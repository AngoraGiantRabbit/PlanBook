# 长期待办三页统一可见性

三页（计划本页、待办页、复盘页）对长期任务采用同一可见性规则：

- **可见区间**：查看日（计划本页/待办页的选中日、复盘页的查看日）落在 `[开始日 .. DDL]` 内才显示；**DDL 之后无论是否完成一律不显示**。
- **区间内**：未完成正常显示（可勾选、可编辑）；手动完成后**划线变灰仍显示、可撤销**，直至 DDL——替代 ADR-0003 早先"完成即从所有视图消失、不可找回"的表述（撤销入口有实际价值，用户 2026-09-14 决策）。
- **复盘页**：未完成 → 「待细化」（按查看日的活跃区间，复盘历史那天看到的是当时的）；完成**当天** → 「当日完成」栏灰色显示（按完成时间戳判定是哪天完成的）；完成次日及以后 → 复盘页完全不显示。
- **过期归档**：DDL 后未完成的仍由 ADR-0003 的惰性标记置 isCompleted（数据卫生）；区间过滤在 UI 层兜底，即使标记未触发过期任务也不显示。过期标记不会让任务混入复盘「当日完成」（完成时刻在 DDL 后，被过滤排除）。

## Considered Options

- **维持各页口径不一**（待办页全量显示）：否决——"已 DDL、已完成的长期待办还在待办页"直接违反用户预期。
- **完成即全页消失**（ADR-0003 原表述严格执行）：否决——失去撤销入口；改为"灰显可撤销至 DDL"。
- **过期任务保留可见（灰显归档）**：否决——用户明确"到 DDL 后无论是否完成三页都不显示"。

## Consequences

- `expandTask` 的 LONG_TERM 分支在数据层做区间过滤（原本无条件放行、依赖各视图自查——待办页从未自查，是本次 bug 根因）；计划本页/小部件的二次过滤变为冗余防御，保留。
- 复盘「当日完成」对长期任务增加完成时间戳判定（completedAt 的日期 == 查看日 且 ≤ DDL），需要 completedAt 在勾选时被正确写入（toggleTaskComplete 已有）。
- 待办页加载路径补触发惰性过期标记（ensureDerivedData），停留待办页也能完成归档。
- 修订 ADR-0003 中"完成后从所有视图消失、不可找回"的表述（见其文末修订注）。
